        Configuración de URL y costo

        La URL de cada faltante se arma como {ruta}/{archivo}. El tamaño de cada lote (1, 2, 4, 8, 16 o 32) se determina sondeando la ruta de mayor a menor y se guarda por lote. Tarifa por default: Supabase Storage (US$0.021/GB-mes; Free incluye 1 GB, Pro 100 GB).

        Ritmo de descarga (cola)

        Controla cuánto se parece a un humano bajando sus fotos. Las descargas salen desde Vercel hacia el origen (p. ej. photoai); un ritmo alto puede hacer que el origen bloquee. Si responde 429/403, la cola se detiene sola y devuelve las fotos a pendientes.

        Tags
